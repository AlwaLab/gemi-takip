# Takip edilen gemiler

Her gemi bu klasörde bir dosyadır:

- Dosya adı: geminin 9 haneli MMSI numarası + `.txt` (ör. `271000835.txt`)
- İçerik (isteğe bağlı): haritada görünecek etiket (ör. `Bizim tanker`)

En kolayı harita sayfasındaki arama kutusundan gemiyi bulup **Takibe al** demektir:
GitHub bu dosyayı hazır doldurulmuş olarak açar, siz sadece **Commit changes** dersiniz.
Takipten çıkarmak için dosyayı silmeniz yeterli (sayfadaki **Takipten çıkar** bağlantısı).
