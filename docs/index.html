    Gemi listesi GitHub'daki ships.json dosyasında durur.

    1. ships.json dosyasını düzenle (GitHub'a giriş yapmış olmalısınız).
    2. Her gemi için bir satır ekleyin; satırlar arasında virgül olmalı:
    {
  "ships": [
    {"mmsi": "271000835", "label": "Bizim tanker"},
    {"mmsi": "240894000", "label": ""}
  ]
}
